# Luna’s Café Landing Page

A fully responsive, one-page landing website for **Luna’s Café**, built with **React**, **TypeScript**, and **Vite**.  
Designed to showcase a cozy, modern café with sections for About, Menu, Gallery, Testimonials, and Contact. Perfect as a demo for small business websites or landing pages.

## Features
- Modern, clean, and cozy design
- Mobile-friendly and fast-loading
- Sections include:
  - Hero
  - About
  - Menu
  - Gallery (Moments at Luna’s)
  - Testimonials
  - Contact form
- Ready for deployment via **Vercel**

## Live Demo
Check it out here: [https://lunas-cafe.vercel.app](https://lunas-cafe.vercel.app)
